# 持久声学资产

本目录保存一套公共模板 `template_pos1.env/.ssp/.bty/.brc`。主线通过 `src/prepare_channels.m` 生成或复用 `arr/` 中的 80 个 ARR，该目录只保留 ARR 和一份 `ARR_SETTINGS.mat`。

不使用哈希目录、程序指纹或文件哈希匹配。`ARR_SETTINGS.mat` 直接记录几何、频率和模板正文；与当前设置一致且 ARR 齐全时直接复用，变化时重建当前结果。没有该记录时也会重新生成，因此更换 Bellhop 程序并需要重算时，移除这份记录即可。

计算时将公共辅助文件复制一次到 `bellhop_work/channel.*`，逐频率更新同一个 `channel.env`，运行后将 `channel.arr` 保存为对应频率的 ARR。全部成功后清理工作文件和目录；失败时保留当前 ENV 和日志。ARR 目录不再为每个频率保留输入文件。

已有 80 个互易 ARR 已从原哈希目录移入 `arr/`，结果保留；400 个逐频率输入/日志副本已清理。本次没有运行 Bellhop。迁移项目时完整携带公共模板、ARR 和配置记录。

`legacy_arr` 保存补回的 80 个旧 4 距离正向几何副本及其一套模板，当前主线不读取，仍保留供历史实验使用。
